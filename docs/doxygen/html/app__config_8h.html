Detailed Description

Compile-time constants and spec defaults for the Tarea 1 firmware.

Runtime-configurable values (waveform, amplitude, sample rate, env period) live in their modules; only their defaults and the allowed ranges are defined here.

#define LINK_BAUD_REVERT_MS   5000
