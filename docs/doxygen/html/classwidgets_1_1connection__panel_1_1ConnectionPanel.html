Detailed Description

Port / baud selectors plus the Conectar and Inicializar ESP32 buttons.

The panel only emits requests; MainWindow performs them and reports back through set_ports() and set_connected().

The baud selector means one thing in both states: the speed the link should run at. It is never the speed the port is opened at - that is always DEFAULT_BAUD, because the board boots into its compile-time rate. Picking another rate while connected renegotiates (baud_change_requested); picking one while disconnected is remembered and MainWindow renegotiates as soon as the connection is up.

Slot for the baud selector: renegotiate now, or leave it to the connect.

While connected this is a request to change the speed of a running link, which only the firmware can grant. While disconnected there is nothing to renegotiate yet, so the value is simply left for target_baud() to be read at connect time.

Parameters
_indexNew combo index (unused; currentData() is read instead).

Repopulate the port list, keeping the current choice if it still exists.

The combo shows the label; the device name travels as item data so that connect_requested carries exactly what pyserial must open. The first entry is preselected, which is the first USB adapter when available_ports() found one.
