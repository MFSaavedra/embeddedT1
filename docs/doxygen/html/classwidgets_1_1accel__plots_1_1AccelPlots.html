Detailed Description

Vertical stack of three pyqtgraph plots fed by per-axis ring buffers.

Producers call push(); the widget redraws itself from a QTimer, so the cost of a frame arriving is just a numpy slice assignment.

◆ _redraw()

None widgets.accel_plots.AccelPlots._redraw ( self)
protected

Timer slot: update the measured rate in each title and repaint the curves.

Unrolls the ring buffer in chronological order, keeps only the last window_s seconds and scrolls the x range so the newest sample sits at the right edge. The measured rate is recomputed once every RATE_WINDOW_S from the samples that arrived in that window (arrivals / elapsed), not per redraw tick.

Sequence[float] values )

Append one batch of samples for axis (called for every ACC frame).

Timestamps are reconstructed as t0 + i / fs. Writes wrap around the ring buffer; nothing is drawn here.

Parameters
axis"X", "Y" or "Z".
t0_msTimestamp of values[0] in ms, as sent by the firmware.
fs_hzSample rate of the batch in Hz (consecutive samples are 1/fs apart).
valuesSample values in g, oldest first; an empty batch is ignored.
