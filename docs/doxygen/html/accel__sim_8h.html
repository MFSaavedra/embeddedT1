Detailed Description

Synthetic tri-axial accelerometer.

Each axis has its own waveform, amplitude and sample rate (spec 2.1.1). A single master tick at ACCEL_TICK_HZ (1 kHz) drives all three axes: an axis at fs Hz emits one sample every ACCEL_TICK_HZ / fs ticks. Samples go through a queue to a streaming task that batches them into ACC frames (accel_sim.c).

Thread model: the tick runs in the esp_timer task, the streaming task is a FreeRTOS task and configuration changes arrive from the UART RX task. The per-axis configuration is therefore only accessed through accel_sim_set_axis() / accel_sim_get_axis(), which use a critical section.

void accel_sim_init ( void )

Create the sample queue, the 1 kHz master timer and the streaming task.

Also resets every axis to the spec defaults. Does not start streaming: that is done by accel_sim_start() (called by the INIT command). Call once, after uart_link_init().
